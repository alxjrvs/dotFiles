# Owner-qualified is load-bearing, not stylistic: `gh ext search stack` returns four same-named

# boom's `gh` pkg manager installs only the misses and never upgrades — matching gh's own
# behavior, which "will check for new versions once every 24 hours and display an upgrade
# notice" rather than installing. So this pins nothing: `gh stack` stays on whatever version
# first landed until someone runs `gh extension upgrade gh-stack`. That remains a live trap for
# a v0.1.0 preview tool, and nothing pins it: `boom lock` covered brew + mise only, and has
# since been removed. Don't read this file as keeping anything current, because it doesn't.
